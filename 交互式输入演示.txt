💡 提示：三种使用模式
═══════════════════════════════════════════════════════════════

模式1: 交互式（推荐新手）
  python main.py name_map.csv
  → 会提示输入通路和物质

模式2: 命令行参数（推荐有经验用户）
  python main.py name_map.csv \
    --pathway "Glycolysis" \
    --compounds "Glucose,Pyruvate"
  → 跳过交互，直接使用参数

模式3: 静默模式（快速运行）
  python main.py name_map.csv --no-interactive
  → 完全跳过交互，不提供额外信息
