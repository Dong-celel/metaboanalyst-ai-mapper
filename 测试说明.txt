📋 测试文件说明
═══════════════════════════════════

已创建的测试文件：
  - test_sample.csv          测试输入（前60种物质）
  - run_test.py             测试运行脚本
  - 测试说明.txt            本文件


🚀 运行测试
═══════════════════════════════════

步骤1: 确保已安装依赖
  pip install -r requirements.txt

步骤2: 运行测试脚本
  python run_test.py

步骤3: 按提示确认是否继续
  - 输入 y 开始测试
  - 其他键取消

步骤4: 等待完成（约5-10分钟）


📊 测试文件统计
═══════════════════════════════════

test_sample.csv 包含：
  - 总物质数: 60
  - 已匹配: 约13个 (Comment=1)
  - 未匹配: 约47个 (Comment=0)

测试将尝试匹配这47个未匹配物质。


💰 费用提醒
═══════════════════════════════════

⚠️  此测试会调用DeepSeek API，产生费用！

预计：
  - API调用次数: ~47次（每个未匹配物质1次）
  - PubChem查询: ~47次（免费）
  - 预计费用: 取决于DeepSeek API定价

建议：
  - 首次测试时先观察前几个物质的匹配情况
  - 可以随时按 Ctrl+C 中断测试


📈 预期输出
═══════════════════════════════════

测试完成后会显示：

1. 耗时统计
2. 匹配成功率
3. 成功匹配的前10个物质
4. 仍未匹配的前10个物质
5. 输出文件: test_sample_matched.csv


✅ 验证结果
═══════════════════════════════════

测试完成后可以：

2. 检查原来 Comment=0 的行
3. 看看是否变成 Comment=1 并填充了数据
4. 验证匹配的物质名称是否合理
