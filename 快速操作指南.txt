🎯 目标：找到MetaboAnalyst"View"功能的API或数据源

═══════════════════════════════════════════════════════════════
方法1: 自动探测（推荐先做）
═══════════════════════════════════════════════════════════════

步骤1: 运行探测脚本
  python 探测_metaboanalyst_api.py

步骤2: 查看输出
  - 如果找到API → 太好了！记下URL
  - 如果没找到 → 继续方法2

═══════════════════════════════════════════════════════════════
方法2: 手动分析（如果方法1失败）
═══════════════════════════════════════════════════════════════

步骤1: 打开MetaboAnalyst
  https://www.metaboanalyst.ca

步骤2: 准备开发者工具
  - 按 F12 打开开发者工具
  - 点击 "Network" 标签
  - 勾选 "Preserve log" 复选框
  - 筛选器选择 "Fetch/XHR"

步骤3: 上传测试文件
  - 上传 test_sample.csv
  - 等待处理完成

步骤4: 触发View操作
  - 找到一个未匹配的物质（Comment=0）
  - 点击它的 "View" 按钮
  - 观察 Network 标签中新增的请求

步骤5: 分析请求
  - 找到返回候选列表的请求（通常是JSON）
  - 点击该请求，查看：
    * Headers 标签 → 记下 Request URL
    * Headers 标签 → 记下 Request Method (GET/POST)
    * Payload 标签 → 记下发送的数据
    * Response 标签 → 查看返回的JSON结构

步骤6: 提供信息
  将以下信息提供给我：
  
  □ Request URL: _________________________________
  
  □ Method: GET / POST (选一个)
  
  □ Request Headers (重要的几个):
    User-Agent: _________________________________
    Content-Type: _______________________________
    其他: _______________________________________
  
  □ Request Payload (如果是POST):
    {
      "参数1": "值1",
      "参数2": "值2"
    }
  
  □ Response 示例 (前几行):
    [
      {
        "name": "...",
        "hmdb": "...",
        ...
      }
    ]

  → 太好了！记下URL和参数，我来实现

  → View内容可能是服务端渲染，需要用Selenium解析

情况3: 有多个请求，不确定哪个是候选列表
  → 提供所有可疑的请求URL，我来分析

情况4: 完全找不到相关请求
  → 可能需要登录或有Session，我们用Selenium Wire方案
