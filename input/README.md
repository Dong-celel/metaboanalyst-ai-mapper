# 待处理文件放这里

1. 把一个 `name_map.csv` 或浓度表 CSV/TXT 放在本目录。
2. 双击 `run.bat`（推荐，纯英文文件名，避免 Windows 编码问题）。
   `开始处理.bat` 也会转到同一个脚本。
3. 处理结果会生成到项目根目录的 `output/<run_id>/`。

运行时的数量提示：直接回车处理全部项目；输入数字则只处理这一批，例如输入 `20`
可先抽样检查 20 个。

随后会一次性询问目标物质、物质类别、目标通路和客户偏好尺度。多个目标请用分号分隔。
偏好尺度 `0` 最严格、`50` 身份与目标并重、`80` 为推荐默认值、`100` 最大程度按客户
目标自动选择。脚本不会再逐项询问，少量无法处理的项目写入内部复核清单。

本目录一次只保留一个 CSV/TXT，避免程序选错文件。
